Put the Thaumaturge jar you build against here (for example `thaumaturge-1.21.1-NeoForge-1.1.0.jar`).

It is only used at compile time and is gitignored. Thaumaturge is All Rights Reserved, so do not commit it.
Alternatively, set `thaumaturge_file_id` in `gradle.properties` to build against CurseForge's Maven mirror instead.
